# PKT-3007 — Hovering the seek bar shows a thumbnail of the frame at that time

## 1. Scope & intent
At 03:24–03:30 the designer notes that VLC "doesn't show a thumbnail as you seek through the video" and proposes it.
The frame at ~03:34 shows, above the thick seek bar of PKT-3006, a dark rounded card holding the frame at the hovered
position and its timecode underneath ("00:02:10"); the elapsed-time label next to the bar shows the same hovered time
while the pointer is over the bar.

Master shows a text tooltip only: the hovered time and, if the media has chapters, the chapter name. libvlccore
already ships a thumbnailer in the preparser API, used today by the media library; the Qt player owns a preparser for
art fetching. Nothing generates frames for the seek bar.

After this packet, hovering (or keyboard-focusing) the seek bar of a **local** video shows a thumbnail above the
tooltip text, generated by the core thumbnailer with a fast seek, cached per position bucket, with at most one request
in flight; network media, audio-only media and the option switched off keep today's text tooltip.

**T3 → three MRs** (§5.5): A the C++ `SeekPreview` controller with a fake backend and its QtTest; B the
preparser-backed backend and an integration row on `mock://`; C the QML card in `SliderBar`.

## 5. Design decisions & open questions
1. **RULED — cost and privacy.** RULED 2026-10-14 (R7): seek thumbnails for local files only, on by default, software decoding, one request in flight; never for network or remote media. Each hover can decode a frame (I/O + CPU, possibly GPU off). Proposed defaults: local
   files only, software decoding (`hw_dec = false`), fast seek, one request in flight, 100 buckets; network/remote never
   (bandwidth, server logs). The option's wording is settled in review.
2. **RULED — preparser ownership.** RULED 2026-10-14 (R0): a dedicated `vlc_preparser_t` (`VLC_PREPARSER_TYPE_THUMBNAIL`) owned by `SeekPreview`. A dedicated `vlc_preparser_t` with `VLC_PREPARSER_TYPE_THUMBNAIL`, created on first
   hover and destroyed on input change, vs. widening `PlayerController`'s art preparser (`modules/gui/qt/player/player_controller.cpp:2118-2126`).
   Proposed: dedicated, owned by `SeekPreview`, so art fetching is never queued behind thumbnails.
3. NOTE — `cfg.external_process` (`vlc_preparser.h`, used as `false` at `modules/gui/qt/player/player_controller.cpp:2124`): a crash in a broken
   file's decoder would take the UI down; consider `true` where supported. Recorded, not decided here.
4. NOTE — thumbnail size: the card is ~160×90 dp at scale 1 (frame ~03:34); request that size times the device pixel ratio.
5. **T3 split.** MR A (~10 h): `SeekPreview` + backend interface + rows 1–7. MR B (~8 h): preparser backend + option + row 8.
   MR C (~10 h): QML card in `SliderBar`, image provider registration (`modules/gui/qt/maininterface/mainui.cpp:164-165`, next to `svgcolor`), rows 9–10.
6. NOTE — new files `player/seek_preview.{hpp,cpp}` go into the Qt sources list and `po/POTFILES.in` (option text strings).
